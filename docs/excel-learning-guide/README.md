# מדריך למידת Excel — הכנה למשרת Data Acceptance Engineer (כלל)

מדריך מובנה, שלב-אחר-שלב, ללמידת Excel מאפס עד רמה שמתאימה לתפקיד **Data Acceptance Engineer** בחברת ביטוח (כלל). המדריך בנוי כך שאפשר לקרוא אותו נוח מהטלפון ב-GitHub (בדף הזה יש כפתור "Raw" / תצוגה רגילה שמתאימה למובייל).

לצד המדריך יש קובץ תרגול אמיתי: **`practice_workbook.xlsx`** (באותה תיקייה) — עם נתונים "מלוכלכים" בסגנון פוליסות/תביעות ביטוח, ותרגילים שאתה פותר בתוך הקובץ.

---

## על התפקיד: מה זה Data Acceptance Engineer?

תפקיד ה-Data Acceptance (לפעמים נקרא גם Data Onboarding / Data Quality / Data Intake) עוסק ב:

- **קליטת קבצי נתונים** ממקורות שונים (ספקים, סוכנויות, מערכות פנימיות) — לרוב בפורמט Excel/CSV.
- **בדיקת תקינות (Validation)**: ערכים חסרים, כפילויות, פורמטים שגויים, ת"ז/מספרי פוליסה לא תקינים, טווחי תאריכים הגיוניים.
- **התאמה/הצלבה (Reconciliation)**: להשוות בין קובץ שהתקבל לבין מקור אמת (למשל טבלת מוצרים, טבלת סוכנים) — כאן `VLOOKUP`/`INDEX-MATCH` הם הכלי המרכזי.
- **סיכום ודיווח**: כמה רשומות התקבלו, כמה נדחו ולמה, פילוח לפי סוכן/מוצר/תאריך — כאן נכנסות **PivotTables**.
- **תיעוד חריגות**: סימון ויזואלי (Conditional Formatting) של שורות בעייתיות לפני שהן עוברות הלאה בתהליך.
- לעיתים גם **אוטומציה** של תהליך הקליטה החוזר (Power Query / מאקרו VBA בסיסי).

המסקנה: אקסל בתפקיד הזה הוא לא "עוד כלי נחמד" — הוא כלי העבודה המרכזי. המדריך בנוי בדיוק סביב היכולות האלה.

## פרק 1 — יסודות: הממשק והמושגים הבסיסיים

- **Workbook / Worksheet**: קובץ = Workbook, ובתוכו כמה גיליונות (Worksheets/Tabs) בתחתית המסך.
- **תא (Cell)**: כתובת לפי עמודה+שורה, למשל `B3`. שורת הנוסחאות (Formula Bar) מעל הגיליון מציגה את התוכן האמיתי של התא.
- **טווח (Range)**: קבוצת תאים, למשל `A1:A10`.
- **סוגי נתונים**: מספר, טקסט, תאריך, אחוז, מטבע — הפורמט של התא (Ctrl+1 → Format Cells) לא משנה את הערך, רק איך הוא מוצג.
- **קיצורים חיוניים**: `Ctrl+C/V`, `Ctrl+Z`, `Ctrl+;` (הכנסת תאריך היום), `Ctrl+Shift+L` (הפעלת סינון), `F2` (עריכת תא), `Ctrl+Arrow` (קפיצה לסוף טווח נתונים), `Alt+=` (סכימה אוטומטית).
- **הפניות יחסיות מול מוחלטות**: `A1` (יחסי — משתנה כשגוררים) מול `$A$1` (מוחלט — קבוע). קריטי בכל נוסחה שגוררים בין שורות.

**תרגול**: גיליון `01_יסודות` — מלאו נתונים בסיסיים, פרמטו עמודת תאריך ועמודת אחוז נכון, ותרגלו הפניה מוחלטת בנוסחת הכפלה באחוז קבוע.

## פרק 2 — נוסחאות בסיסיות

| נוסחה | שימוש |
|---|---|
| `=SUM(range)` | סכימה |
| `=AVERAGE(range)` | ממוצע |
| `=COUNT(range)` | ספירת תאים עם מספרים |
| `=COUNTA(range)` | ספירת תאים לא ריקים (כל סוג) |
| `=COUNTBLANK(range)` | ספירת תאים ריקים — קריטי לבדיקת שדות חסרים |
| `=IF(condition, value_if_true, value_if_false)` | תנאי בסיסי |
| `=COUNTIF(range, criteria)` | ספירה לפי תנאי |
| `=SUMIF(range, criteria, sum_range)` | סכימה לפי תנאי |
| `=COUNTIFS(...)` / `=SUMIFS(...)` | אותו דבר עם כמה תנאים במקביל |

דוגמה שרלוונטית לתפקיד: `=COUNTBLANK(B2:B500)` בעמודת "מספר פוליסה" מגלה מיד כמה רשומות חסרות מזהה — בדיקת קבלה קלאסית.

**תרגול**: גיליון `02_נוסחאות_בסיסיות` — חשבו סה"כ פרמיה, ממוצע פרמיה לפי סוג פוליסה, וספרו רשומות עם שדה חסר.

## פרק 3 — עבודה עם נתונים: מיון, סינון, ניקוי

- **מיון (Sort)**: לפי עמודה אחת או כמה עמודות (Data → Sort).
- **סינון (Filter)**: `Ctrl+Shift+L` להפעלת חצי סינון בכותרות.
- **הסרת כפילויות**: Data → Remove Duplicates — אבל **תמיד** קודם לבדוק/לסמן, לא רק למחוק בעיוורון.
- **Text to Columns**: לפיצול עמודה (למשל "שם מלא" ל"שם פרטי"+"משפחה", או תאריך שנכנס כטקסט).
- **פונקציות ניקוי טקסט**:
  - `=TRIM(text)` — מסיר רווחים מיותרים.
  - `=CLEAN(text)` — מסיר תווים לא מודפסים (נפוץ בקבצים מיובאים).
  - `=UPPER/LOWER/PROPER(text)` — אחידות אותיות.
  - `=LEFT(text,n)` / `=RIGHT(text,n)` / `=MID(text,start,n)` — חיתוך מחרוזת (למשל חילוץ קידומת ת"ז).
  - `=CONCATENATE(a,b)` או `=a&b` — חיבור מחרוזות.
  - `=TEXT(value, format)` — המרת מספר/תאריך למחרוזת בפורמט קבוע.
- **Data Validation** (Data → Data Validation): הגבלת מה שאפשר להקליד בתא (למשל רק תאריך בטווח הגיוני, או רשימה סגורה) — משמש גם למניעת טעויות וגם להבנת כללי קבילות.

**תרגול**: גיליון `03_ניקוי_נתונים` — טבלת פוליסות "מלוכלכת" (רווחים מיותרים, אותיות גדולות/קטנות לא אחידות, כפילויות, תאריכים כטקסט). המשימה: לנקות ולהכין לעיבוד.

## פרק 4 — VLOOKUP / INDEX-MATCH / XLOOKUP (הליבה של "Acceptance")

זה אולי הכלי **הכי חשוב** לתפקיד — השוואת קובץ נכנס מול טבלת ייחוס.

```
=VLOOKUP(lookup_value, table_array, col_index_num, FALSE)
```
- `FALSE` בסוף = התאמה מדויקת (כמעט תמיד מה שרוצים בבדיקת קבילות).
- מגבלה: מחפש רק מימין לעמודת החיפוש.

```
=INDEX(return_range, MATCH(lookup_value, lookup_range, 0))
```
- גמיש יותר — יכול לחפש גם "שמאלה", ולא נשבר אם מוסיפים עמודות.

```
=XLOOKUP(lookup_value, lookup_array, return_array, "לא נמצא")
```
- הגרסה המודרנית (אם יש בגרסת האקסל בעבודה) — כוללת טיפול מובנה במקרה "לא נמצא".

**שימוש טיפוסי בתפקיד**: מולידים עמודה "האם קוד המוצר קיים בטבלת המוצרים הרשמית?" באמצעות `VLOOKUP`/`XLOOKUP`, וכל `#N/A` הוא רשומה שנופלת ודורשת בדיקה.

**תרגול**: גיליון `04_VLOOKUP` — טבלת תביעות מול טבלת "קודי מוצר" רשמית. המשימה: להצליב, לזהות קודים לא קיימים ולמשוך שם סוכן לפי מספר סוכן.

## פרק 5 — PivotTables (טבלאות ציר) לסיכום ודיווח

- Insert → PivotTable, בוחרים טווח/טבלה.
- גוררים שדה לאזור **Rows** (למשל "סוג פוליסה"), שדה ל-**Values** (למשל "פרמיה" עם Sum או Count).
- אפשר להוסיף **Columns** (למשל שנה) ו-**Filters** (למשל סוכן ספציפי).
- **Count** מציג "כמה רשומות" — שימושי לדוח "כמה רשומות התקבלו/נדחו".
- לחיצה ימנית → **Value Field Settings** לשינוי מ-Sum ל-Count/Average.
- ריענון אחרי שינוי נתונים: כפתור **Refresh** (או Ctrl+Alt+F5).

**תרגול**: גיליון `05_PivotTable` — בנו טבלת ציר שמראה סה"כ פרמיה וכמות פוליסות לפי סוכן ולפי חודש.

## פרק 6 — Conditional Formatting לזיהוי חריגות

- Home → Conditional Formatting.
- כללי "מובנים": Highlight Cells Rules (למשל "גדול מ-"), Top/Bottom, Data Bars, Color Scales.
- **כלל מבוסס נוסחה** (החזק ביותר) — New Rule → "Use a formula to determine which cells to format":
  - לדוגמה: `=COUNTIF($B$2:$B$500,B2)>1` יצבע כפילויות בעמודת מספר פוליסה.
  - לדוגמה: `=ISBLANK(C2)` יצבע שדה חסר.
  - לדוגמה: `=B2<DATE(2000,1,1)` יצבע תאריך לא הגיוני.

זה בדיוק סוג הבדיקות שתפקיד Data Acceptance עושה כל יום — הפיכת בעיות נתונים ל"נראות לעין" מיידית.

**תרגול**: גיליון `06_Conditional_Formatting` — סמנו אוטומטית שורות עם: פרמיה שלילית, תאריך עתידי, ומספר פוליסה כפול.

## פרק 7 — בדיקות תקינות מתקדמות (Data Quality Checklist)

טכניקת עבודה מומלצת: להוסיף בקובץ עמודת "בדיקה" לכל כלל, ועמודת "תוצאה" מסכמת.

| בדיקה | נוסחה לדוגמה |
|---|---|
| שדה חובה חסר | `=IF(A2="","חסר","תקין")` |
| כפילות מזהה | `=IF(COUNTIF($A$2:$A$500,A2)>1,"כפול","ייחודי")` |
| טווח תאריך הגיוני | `=IF(OR(B2<DATE(2015,1,1),B2>TODAY()),"חריג","תקין")` |
| ערך מספרי שלילי | `=IF(C2<0,"שלילי - לבדיקה","תקין")` |
| קיום בטבלת ייחוס | `=IFERROR(VLOOKUP(D2,ProductTable,1,FALSE),"לא נמצא במקור")` |
| סיכום כולל | `=IF(COUNTA(E2:H2)=0,"עבר את כל הבדיקות","נדחה")` — או שילוב עם COUNTIF על תוצאות "תקין" |

**תרגול**: גיליון `07_Data_Quality` — בנו "עמודת שער" (Gate Column) אחת שמסכמת אם רשומה "קבילה" או "נדחית", על סמך כל הבדיקות שלמדתם.

## פרק 8 — Power Query (בסיס ETL באקסל)

Power Query הוא בדיוק העולם של "ETL" (Extract-Transform-Load) בתוך Excel — רלוונטי מאוד לשם התפקיד ולריפו שבו נמצא המדריך הזה.

- נמצא ב-Data → Get Data / From Table-Range.
- מאפשר: ניקוי עמודות, שינוי סוגי נתונים, מיזוג (Merge) שני מקורות (כמו VLOOKUP אבל חזק וניתן לתיעוד/חזרה), חיבור (Append) קבצים דומים אחד לשני, וטעינה חוזרת אוטומטית כשמרעננים.
- כל שלב נשמר כ"Applied Step" — שקוף ואפשר לתקן, בניגוד לנוסחה חד-פעמית.
- אם מכירים Python/SQL — Power Query הוא ה"שפה החזותית" המקבילה של Excel לעיבוד נתונים, ושווה להזכיר בראיון.

**תרגול (אופציונלי, לרמה מתקדמת יותר)**: גיליון `08_Power_Query_עיון` — הנחיות איך לייבא ולנקות את `נתוני_תרגול` דרך Power Query במקום נוסחאות ידניות.

## פרק 10 — הכנה לראיון: מונחים ושאלות נפוצות

**שאלות טכניות אפשריות:**
1. "איך היית בודק אם קובץ Excel שקיבלת עומד בדרישות איכות בסיסיות?" → תשובה: COUNTBLANK, COUNTIF לכפילויות, Conditional Formatting לחריגות, VLOOKUP מול טבלת ייחוס.
2. "מה ההבדל בין VLOOKUP ל-INDEX/MATCH?" → כיוון חיפוש, יציבות מול הוספת עמודות.
3. "איך היית מציג לצוות כמה רשומות נדחו והסיבות?" → PivotTable + עמודת "סיבת דחייה".
4. "מה זה Power Query ולמה הוא עדיף על נוסחאות בתהליך חוזר?" → תיעוד שלבים, ריענון קל, פחות שגיאות ידניות.
5. "איך היית מוודא שמספר פוליסה תקין?" → שילוב Data Validation + נוסחת בדיקת אורך/תבנית (`LEN`, `ISNUMBER`, `COUNTIF`).

**מונחים כדאי להכיר**: Data Validation, Reconciliation, Data Quality Gate, Deduplication, Source of Truth, Exception Report, Refresh/ETL.

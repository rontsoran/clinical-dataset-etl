על התפקיד: מה זה Data Acceptance Engineer?

תפקיד ה-Data Acceptance (לפעמים נקרא גם Data Onboarding / Data Quality / Data Intake) עוסק ב:

  • קליטת קבצי נתונים ממקורות שונים (ספקים, סוכנויות, מערכות פנימיות) — לרוב בפורמט Excel/CSV.
  • בדיקת תקינות (Validation): ערכים חסרים, כפילויות, פורמטים שגויים, ת"ז/מספרי פוליסה לא תקינים, טווחי תאריכים הגיוניים.
  • התאמה/הצלבה (Reconciliation): להשוות בין קובץ שהתקבל לבין מקור אמת (למשל טבלת מוצרים, טבלת סוכנים) — כאן VLOOKUP/INDEX-MATCH הם הכלי המרכזי.
  • סיכום ודיווח: כמה רשומות התקבלו, כמה נדחו ולמה, פילוח לפי סוכן/מוצר/תאריך — כאן נכנסות PivotTables.
  • תיעוד חריגות: סימון ויזואלי (Conditional Formatting) של שורות בעייתיות לפני שהן עוברות הלאה בתהליך.
  • לעיתים גם אוטומציה של תהליך הקליטה החוזר (Power Query / מאקרו VBA בסיסי).

המסקנה: אקסל בתפקיד הזה הוא לא "עוד כלי נחמד" — הוא כלי העבודה המרכזי. המדריך בנוי בדיוק סביב היכולות האלה.

איך להשתמש במדריך

  1. עברו על הפרקים לפי הסדר — כל פרק בונה על הקודם.
  2. בסוף כל פרק יש תרגול — פתחו את practice_workbook.xlsx ובצעו את המשימה בגיליון המתאים.
  3. אם נתקעתם, בגיליון פתרונות בקובץ התרגול יש נוסחאות פתרון עם הסבר קצר.
  4. יעד זמן מוצע: פרק ליום/יומיים, כ-2-3 שבועות עד רמה טובה לראיון.

פרק 1 — יסודות: הממשק והמושגים הבסיסיים

  • Workbook / Worksheet: קובץ = Workbook, ובתוכו כמה גיליונות (Worksheets/Tabs) בתחתית המסך.
  • תא (Cell): כתובת לפי עמודה+שורה, למשל B3. שורת הנוסחאות (Formula Bar) מעל הגיליון מציגה את התוכן האמיתי של התא.
  • טווח (Range): קבוצת תאים, למשל A1:A10.
  • סוגי נתונים: מספר, טקסט, תאריך, אחוז, מטבע — הפורמט של התא (Ctrl+1 → Format Cells) לא משנה את הערך, רק איך הוא מוצג.
  • קיצורים חיוניים: Ctrl+C/V, Ctrl+Z, Ctrl+; (תאריך היום), Ctrl+Shift+L (סינון), F2 (עריכת תא), Ctrl+Arrow (קפיצה לסוף טווח), Alt+= (סכימה אוטומטית).
  • הפניות יחסיות מול מוחלטות: A1 (יחסי) מול $A$1 (מוחלט). קריטי בכל נוסחה שגוררים בין שורות.
תרגול: גיליון 01_יסודות — מלאו נתונים בסיסיים, פרמטו עמודת תאריך ואחוז נכון, ותרגלו הפניה מוחלטת בנוסחת הכפלה באחוז קבוע.

פרק 2 — נוסחאות בסיסיות

נוסחהשימוש
=SUM(range)סכימה
=AVERAGE(range)ממוצע
=COUNT(range)ספירת תאים עם מספרים
=COUNTA(range)ספירת תאים לא ריקים
=COUNTBLANK(range)ספירת תאים ריקים — קריטי לבדיקת שדות חסרים
=IF(cond, a, b)תנאי בסיסי
=COUNTIF(range, criteria)ספירה לפי תנאי
=SUMIF(range, criteria, sum_range)סכימה לפי תנאי
=COUNTIFS(...) / =SUMIFS(...)כמה תנאים במקביל

דוגמה רלוונטית לתפקיד: =COUNTBLANK(B2:B500) בעמודת "מספר פוליסה" מגלה מיד כמה רשומות חסרות מזהה.

תרגול: גיליון 02_נוסחאות_בסיסיות — חשבו סה"כ פרמיה, ממוצע פרמיה לפי סוג מוצר, וספרו רשומות עם שדה חסר.

פרק 3 — עבודה עם נתונים: מיון, סינון, ניקוי

  • מיון (Sort): לפי עמודה אחת או כמה עמודות (Data → Sort).
  • סינון (Filter): Ctrl+Shift+L להפעלת חצי סינון בכותרות.
  • הסרת כפילויות: Data → Remove Duplicates — אבל תמיד קודם לבדוק/לסמן, לא רק למחוק בעיוורון.
  • Text to Columns: לפיצול עמודה (למשל "שם מלא" ל"שם פרטי"+"משפחה").
  • ניקוי טקסט: =TRIM(), =CLEAN(), =UPPER/LOWER/PROPER(), =LEFT/RIGHT/MID(), =a&b, =TEXT(value, format).
  • Data Validation (Data → Data Validation): הגבלת מה שאפשר להקליד בתא.
תרגול: גיליון 03_ניקוי_נתונים — טבלת פוליסות "מלוכלכת" (רווחים מיותרים, אותיות לא אחידות, כפילויות). המשימה: לנקות ולהכין לעיבוד.

פרק 4 — VLOOKUP / INDEX-MATCH / XLOOKUP (הליבה של Acceptance)

זה אולי הכלי הכי חשוב לתפקיד — השוואת קובץ נכנס מול טבלת ייחוס.

=VLOOKUP(lookup_value, table_array, col_index_num, FALSE)

FALSE בסוף = התאמה מדויקת. מגבלה: מחפש רק מימין לעמודת החיפוש.

=INDEX(return_range, MATCH(lookup_value, lookup_range, 0))

גמיש יותר — יכול לחפש גם "שמאלה", ולא נשבר כשמוסיפים עמודות.

=XLOOKUP(lookup_value, lookup_array, return_array, "לא נמצא")

הגרסה המודרנית — כוללת טיפול מובנה במקרה "לא נמצא".

שימוש טיפוסי בתפקיד: עמודת "האם קוד המוצר קיים בטבלת המוצרים הרשמית?" — כל #N/A הוא רשומה שנופלת ודורשת בדיקה.
תרגול: גיליון 04_VLOOKUP — טבלת פוליסות מול טבלת "קודי מוצר" רשמית. המשימה: להצליב, לזהות קודים לא קיימים ולמשוך שם סוכן לפי קוד סוכן.

פרק 5 — PivotTables (טבלאות ציר) לסיכום ודיווח

  • Insert → PivotTable, בוחרים טווח/טבלה.
  • גוררים שדה ל-Rows, שדה ל-Values (Sum או Count).
  • אפשר להוסיף Columns ו-Filters.
  • Count מציג "כמה רשומות" — שימושי לדוח "כמה התקבלו/נדחו".
  • לחיצה ימנית → Value Field Settings לשינוי Sum/Count/Average.
  • ריענון: כפתור Refresh (Ctrl+Alt+F5).
תרגול: גיליון 05_PivotTable — בנו טבלת ציר שמראה סה"כ פרמיה וכמות פוליסות לפי סוכן ולפי חודש.

פרק 6 — Conditional Formatting לזיהוי חריגות

  • Home → Conditional Formatting.
  • כללים מובנים: Highlight Cells Rules, Top/Bottom, Data Bars, Color Scales.
  • כלל מבוסס נוסחה (החזק ביותר) — New Rule → "Use a formula to determine which cells to format":
    • =COUNTIF($B$2:$B$500,B2)>1 — כפילויות
    • =ISBLANK(C2) — שדה חסר
    • =B2<DATE(2000,1,1) — תאריך לא הגיוני

זה בדיוק סוג הבדיקות שתפקיד Data Acceptance עושה כל יום — הפיכת בעיות נתונים ל"נראות לעין" מיידית.

תרגול: גיליון 06_Conditional_Formatting — סמנו אוטומטית שורות עם פרמיה שלילית, תאריך עתידי, ומספר פוליסה כפול.

פרק 7 — בדיקות תקינות מתקדמות (Data Quality Checklist)

טכניקת עבודה מומלצת: להוסיף עמודת "בדיקה" לכל כלל, ועמודת "תוצאה" מסכמת.

בדיקהנוסחה לדוגמה
שדה חובה חסר=IF(A2="","חסר","תקין")
כפילות מזהה=IF(COUNTIF($A$2:$A$500,A2)>1,"כפול","ייחודי")
טווח תאריך הגיוני=IF(OR(B2<DATE(2015,1,1),B2>TODAY()),"חריג","תקין")
ערך מספרי שלילי=IF(C2<0,"שלילי","תקין")
קיום בטבלת ייחוס=IFERROR(VLOOKUP(D2,ProductTable,1,FALSE),"לא נמצא")
סיכום כולל (שער קבילות)=IF(OR(E2="חסר",F2="כפול",G2="חריג",H2="שלילי"),"נדחה","קביל")

הרעיון: משלבים את תוצאות כל הבדיקות הקודמות בתנאי OR אחד, שמחזיר החלטה סופית אחת וברורה.

תרגול: גיליון 07_Data_Quality — בנו "עמודת שער" (Gate Column) אחת שמסכמת אם רשומה "קבילה" או "נדחית".

פרק 8 — Power Query (בסיס ETL באקסל)

Power Query הוא בדיוק העולם של "ETL" (Extract-Transform-Load) בתוך Excel — רלוונטי מאוד לשם התפקיד.

  • נמצא ב-Data → Get Data / From Table-Range.
  • מאפשר: ניקוי עמודות, שינוי סוגי נתונים, מיזוג (Merge) שני מקורות, חיבור (Append) קבצים, טעינה חוזרת אוטומטית.
  • כל שלב נשמר כ-"Applied Step" — שקוף וניתן לתיקון, בניגוד לנוסחה חד-פעמית.
  • אם מכירים Python/SQL — Power Query הוא ה"שפה החזותית" המקבילה לעיבוד נתונים, ושווה להזכיר בראיון.
תרגול (אופציונלי, לרמה מתקדמת יותר): גיליון 08_Power_Query — הנחיות שלב-אחר-שלב איך לייבא ולנקות את נתוני 03_ניקוי_נתונים דרך Power Query במקום נוסחאות ידניות.

פרק 9 — מאקרו/VBA בסיסי (רשות)

  • Developer → Record Macro: מקליטים פעולה חוזרת ומקבלים קוד VBA אוטומטית.
  • שימושי לאוטומציה של תהליך קליטה חוזר (למשל "נקה + סמן חריגות + שמור כ-PDF" בלחיצת כפתור).
  • לא חובה לשליטה מלאה בתחילת התפקיד — אבל שווה להכיר, ו-Alt+F11 פותח את עורך ה-VBA.

פרק 10 — הכנה לראיון: מונחים ושאלות נפוצות

שאלות טכניות אפשריות:

  1. "איך היית בודק אם קובץ Excel שקיבלת עומד בדרישות איכות בסיסיות?" → COUNTBLANK, COUNTIF לכפילויות, Conditional Formatting לחריגות, VLOOKUP מול טבלת ייחוס.
  2. "מה ההבדל בין VLOOKUP ל-INDEX/MATCH?" → כיוון חיפוש, יציבות מול הוספת עמודות.
  3. "איך היית מציג כמה רשומות נדחו והסיבות?" → PivotTable + עמודת "סיבת דחייה".
  4. "מה זה Power Query ולמה הוא עדיף על נוסחאות בתהליך חוזר?" → תיעוד שלבים, ריענון קל, פחות שגיאות ידניות.
  5. "איך היית מוודא שמספר פוליסה תקין?" → Data Validation + נוסחת בדיקת אורך/תבנית (LEN, ISNUMBER, COUNTIF).

מונחים כדאי להכיר: Data Validation, Reconciliation, Data Quality Gate, Deduplication, Source of Truth, Exception Report, Refresh/ETL.
